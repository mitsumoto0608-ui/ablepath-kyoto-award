# P15 UI_OVERCLAIM_OR_INFORMATION_OVERLOAD

必要性: confidence/constraintを隠すとoverclaim、全metadataを常時出すとactionabilityを失う。

- BEST_SOURCE_FOR_DEFINITION=S010 — inclusive pedestrian information guidance, ADAPT
- BEST_SOURCE_FOR_METHOD=S026 — focused audit UI Sections 3–6, ADAPT
- BEST_SOURCE_FOR_VALIDATION=S023 — severity interpretation conflict, ADAPT
- BEST_SOURCE_FOR_LIMITATION=S029 — personalization Sections 2–5, STRUCTURE_ONLY

使えるclaim: claim strength、unknown、source/date、profile constraintを段階表示する。

使えないclaim: safe badge、one-size accessible route、crowd severityを法的statusとして表示。

TARGET_VALIDATION_REQUIREMENT: disabled/older/visual-impairment usersを含むtask-based comprehension/error test。
