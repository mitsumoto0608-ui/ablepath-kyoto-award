# P13 MULTI_SOURCE_CONFLICT

必要性: 同じfeatureでもdefinition、date、method、population、versionが違えば値は平均できない。

- BEST_SOURCE_FOR_DEFINITION=S023 — dataset definition/severity conflict, results, ADAPT
- BEST_SOURCE_FOR_METHOD=S005 — metadata/quality Chapters 6–8, DIRECT
- BEST_SOURCE_FOR_VALIDATION=S020 — nominal/effective width Table 4, ADAPT
- BEST_SOURCE_FOR_LIMITATION=S015 — population-specific debris pp.10–14, ADAPT

使えるclaim: 両値とscope/version/dateを保持し、contradiction reasonを分類する。

使えないclaim: numeric average、自動優先順位、foreign/local coefficient混合。

TARGET_VALIDATION_REQUIREMENT: like-for-like definition/date alignment、independent field/official check、adjudication log。
