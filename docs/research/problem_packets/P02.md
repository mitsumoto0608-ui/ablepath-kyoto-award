# P02 CRS_AXIS_ORDER_MISMATCH

必要性: 同一CRS名でもaxis sequence/unit/vertical datumの誤解は位置ずれや偽overlapを生む。

- BEST_SOURCE_FOR_DEFINITION=S001 — WKT2 Axis order section, DIRECT
- BEST_SOURCE_FOR_METHOD=S005 — PLATEAU Chapter 5, DIRECT
- BEST_SOURCE_FOR_VALIDATION=S006 — JGD2011 (B,L) declaration, DIRECT
- BEST_SOURCE_FOR_LIMITATION=S030 — multi-source fusion methods, ADAPT

使えるclaim: CRS、axis order、unit、horizontal/vertical datumを別々に検証する。

使えないclaim: EPSG codeが同じなら座標列も同じ。map上で概ね重なるので正しい。

TARGET_VALIDATION_REQUIREMENT: known control pointsのround-trip、bounds、axis swap test、official map comparison。
