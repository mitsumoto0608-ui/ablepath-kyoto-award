# Orchestration

## Blocking path

1. Verify GitHub anchor and baseline.
2. Inventory Phase 3 Arashiyama/Fujisawa branches and retained raw evidence without mutating them.
3. Build each city artifact in one isolated writer worktree.
4. Accept only source/hash/lineage-complete artifacts into integration.
5. Add shared deterministic analysis and existing-viewer integration after both city artifacts resolve.

## Parallel packets

- `ARA-P0`: one Terra/medium writer, isolated worktree, owns only Arashiyama city/data/docs/tests/report paths.
- `FUJ-P0`: one Terra/medium writer, isolated worktree, owns only Fujisawa city/data/docs/tests/report paths.
- `CONTRACT-AUDIT`: one Luna/low read-only worker inventories M6/Hokonavi evidence and safety/provenance conflicts; no writes.

## Sequential CONTROL work

- Integrate accepted city commits.
- Write tests first for one shared deterministic analysis module at most.
- Extend the current MapLibre manifest/domain/UI without a new app or framework.
- Produce M7 reasoned-null readiness, gate JSON, screenshots, reports, freeze packets, final verification, RC A/B, and draft PR.

## Acceptance policy

No city becomes GREEN from a report alone. Raw receipt, normalized hash chain, topology QA, and fatal mismatch test must agree. Official hazard remains `NOT_CONNECTED` unless its trust chain is complete. Candidate path means graph connectivity only; it is never a safety, accessibility, passability, opening, or recommendation claim.

## Stop rules

After three identical failure fingerprints, stop that lane and preserve an exact blocker. At the hard deadline, stop new features and finish only atomic integration, verification, receipts, CI, RC, and the draft PR. Stop at the human gate without main merge, tag, release, or automatic contract freeze.
